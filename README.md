# NutriFlow

NutriFlow is a full-stack nutrition tracking project built as part of the Scaler Neovarsity Woolf Applied Software Project.

The product focus is simple:
- log meals quickly using natural language
- view day-wise calorie and macro progress
- correct logs through edit/delete flows
- get lightweight nutrition guidance from chat
